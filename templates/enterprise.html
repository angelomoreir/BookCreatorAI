Perguntas Frequentes

Qual é o número mínimo de licenças?

Para o plano Educação são necessárias no mínimo 10 licenças. Para o plano Empresarial, o mínimo é de 5 licenças.

Oferecem período de teste gratuito?

Sim! Oferecemos 30 dias de teste gratuito para organizações, com acesso completo a todas as funcionalidades.

Como funciona a faturação?

A faturação é mensal ou anual (com 2 meses grátis). Emitimos faturas com todos os requisitos legais para organizações.

É possível integrar com o nosso LMS?

Sim, oferecemos integração via API com os principais sistemas LMS (Moodle, Canvas, etc.) no plano Empresarial e Enterprise.
