🔑 A tua chave de API do Gemini

Para usares a app, precisas da tua própria chave gratuita do Google Gemini. Demora menos de 1 minuto a obter.

Como obter a chave

  1. 1 Abre o Google AI Studio e inicia sessão com a tua conta Google.
  2. 2 Clica em "Get API key" → "Create API key".
  3. 3 Copia a chave gerada (começa por AIza...).
  4. 4 Cola-a no campo abaixo e guarda.

ℹ️ A chave é gratuita — a Google oferece um nível gratuito generoso. Fica guardada apenas na tua conta e nunca é partilhada.
